# Operational runbooks

[Back to the complete documentation index](../README.md).

The prototype guide covers the development build. Genesis and signing remain
planned procedures; those runbooks do not record completed bring-up or successful
drills.

| Runbook | Purpose |
|---|---|
| [Prototype build](PROTOTYPE.md) | Build and test the portable C++ CLI with Docker or local tools. |
| [Genesis](GENESIS.md) | Initial project bring-up and recovery after total loss. |
| [Signing, recovery, and key rotation](KEY-RUNBOOK.md) | Signing operations, key setup and rotation, recovery, and drills. |

Read Genesis for initial bring-up or recovery after total loss. Read the Key
Runbook for signing operations and drills.
