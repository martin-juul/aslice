## Captured material

The historical overview dates Homebrew to 2009, version 1 to September 2016, version 2 to February 2019, Apple-silicon support in version 3 to February 2021, and default JSON formula downloads in version 4 to February 2023. Its version table places Monterey deprecation in version 4.4 (October 2024). This is background only; the archived Homebrew release and support-policy records take precedence for project decisions.

## Decision-relevant context

Source locator: History and version/release table. The live article revision ID was not pinned by the earlier archive.

The timeline distinguishes project creation, numbered releases, architecture support, and metadata distribution. Version 2 integrates Linux support; version 3 adds Apple-silicon support; version 4 changes default formula acquisition to the JSON API. These are different milestones, not evidence that the same OS support policy applied throughout.

The article's Monterey/version-table date should not be used as the first date users lost CI support: the [September 2024 discussion](HOMEBREW_MONTEREY_DISCUSSION_5603.MD) already records a warning and reallocation of Monterey CI. The earlier summary's October 2024 version-4.4 association is retained as secondary chronology, not substituted for that participant evidence.
